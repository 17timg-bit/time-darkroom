# 暮光模型

## 内置景片

岬角灯塔和镜湖沿用[天象模型](天象模型.md)中的日期、参考站和镜头。画面各处先确定曝光时刻，再求太阳高度及方位。天空使用按太阳高度、视线高度和相对方位插值的大气散射数据。原景片提供云层纹理和地形。岩石、植被、雪面按直射光和漫射光变化，水面取反射方向的散射光，镜湖还用原有遮罩保留山体倒影。近午夜的画面保留暗部层次，星空随暮光减弱而显现。

散射数据来自 Prague Sky Model 的地面版，采样能见度 45 km、反照率 0.18、太阳高度 −4° 至 +52°。57 个太阳高度平面存成 48 × 1140 的对数 RGB 纹理。低于 −4° 时继续衰减并逐渐冷却。这个区间的外推、云的透光估计、暗部亮度和器材曝光是成像选择。画面使用固定天气假设。光谱到 XYZ 使用 Wyman 等人的解析近似。 [Prague 论文](https://cgg.mff.cuni.cz/publications/skymodel-2021/) · [Apache 2.0 数据集](https://doi.org/10.5281/zenodo.19140728) · [参考实现](https://github.com/PetrVevoda/pragueskymodel/tree/2385c912e9051c1258013ff8c3ce2e19e10fb917) · [色彩匹配函数](https://jcgt.org/published/0002/02/01/)

## 自带景片

单张照片在浏览器内生成一张 192 × 108 的天空置信度图，再对天空、地物和高光施加不同的光线变化。用户可在取景台校准当地日出和日落。默认采用 06:00 和 18:00。拍摄时刻使用裁切后的原片，单张的其它时刻属于光线推演。同机位多张「柔接」在对数亮度空间插值，纹理在较短的过渡区间接力。运动明显的景片可用「切片」直接切换拍摄样本。

轻量逻辑回归使用下表 9 段公开延时各 40 帧、147,120 个标注区域像素拟合。逐个留出整段视频时，抽样区域的平衡分类准确率为 87.3%–100.0%。这些数字衡量手工选定的天空和地物区域，实际轮廓由浏览器按照片估计。3 段有足够可用亮度变化的序列为地面亮度响应提供标定。发布的网页只加载系数和大气采样纹理，用户照片的分析、合成与导出均在当前浏览器执行。

## 重建

在仓库根目录运行。大气采样使用 Ground 数据集 `PragueSkyModelDatasetGround.dat`，MD5 为 `953864f62c9434269b7f909cdff6c7cd`。将固定版本的 `PragueSkyModel.h` 和 `PragueSkyModel.cpp` 放入 `sky-source`。Python 脚本使用 NumPy、Pillow 和 imageio-ffmpeg。

```sh
g++ -O2 -std=c++17 -include array -include tuple -I sky-source scripts/sample-atmosphere.cpp sky-source/PragueSkyModel.cpp -o sample-atmosphere
./sample-atmosphere PragueSkyModelDatasetGround.dat radiance.bin
python scripts/build-atmosphere.py radiance.bin
python scripts/fit-field-light.py /path/to/public/clips
```

浏览网页时可直接使用生成后的两项资源。散射纹理与参考数据的许可随仓库提供。 [Apache 2.0 许可](../vendor/Prague-Sky-Model-LICENSE.txt)
